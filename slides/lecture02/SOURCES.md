# 第2章の出典と図版

- 本文・学習順序: `chapters/chapter02-drawing-shapes.tex`。
- コード: `typescript-p5/listings/chapter02/` の5本。教材の元ファイルは変更していません。
- PNG: `scripts/capture-lecture02.mjs` により、元コードと数値変更版をp5.jsで実行してキャンバスを撮影。静止画なのでPDFでも比較できます。

- 外部の写真、ロゴ、生成イラストは使用していません。
